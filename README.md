# taobao-user-behavior-analysis#
淘宝用户行为数据分析 (Taobao User Behavior Analysis)
## 📌 项目背景
基于阿里云天池淘宝用户行为公开数据集（抽样 110 万条记录，跨度近一年），使用 MySQL 进行数据清洗与业务指标提取，旨在分析用户转化漏斗、挖掘高潜力品类，并定位流失用户特征，为电商运营提供数据支持。

## 🛠️ 技术栈与工具
- **数据库**：MySQL
- **工具**：Navicat
- **核心技能**：数据清洗 (ALTER/CAST)、条件聚合 (CASE WHEN)、子查询、漏斗模型、用户行为分析

## 核心业务发现
1. **转化漏斗**：整体漏斗呈现浏览(10727) -> 加购(8106) -> 购买(7394)。发现存在 **2240名“加购未买”** 的流失用户，构成精准营销的挽回池。
2. **品类效率**：通过对比头部品类转化率，定位到高转化的“明星品类（如ID 4145813，转化率7.56%）”及高流量低转化的“洼地品类（如ID 2355072，转化率2.67%）”，建议差异化分配流量。
3. **时间规律**：发现周一是用户浏览高峰期，建议作为大促与资源投放的关键节点。

## 文件说明
- `analysis_queries.sql`：包含漏斗、品类、复购用户等核心分析的 SQL 脚本。
- `data_quality.md`：数据字典及清洗过程说明。
- `report.pdf`：完整的数据分析报告（含业务建议）。
